# B站直播监听（内置插件）

> 状态：已内嵌为官方内置插件，默认开启（2026-10-19）。
> 目录：app/src/neobot_app/builtin_plugins/streaming_parser/；官方来源，可在面板启停/重载，不能安装/更新/卸载。
> 许可：MIT（上游 SuperQuail/NeoBot_StreamingParser，版本 0.3.1）。
> 注意：本插件只负责开播/下播监听与通知；直播弹幕交互是 B站模块的 /直播互动 命令，**与监听分开、不绑定**。

## 能力

- 监听 B 站直播间（房间号/短号/直播间链接/UP 主空间链接），按群保存订阅。
- 轮询开播/下播（默认 60s），跳变时推送卡片；可选推送后触发一次 AI 回复。
- 开播状态总览图（头像 + 昵称 + 直播中粉色圆环）。
- 三种卡片风格：sakura / neon / minimal，默认随机。
- 依赖复用本体 httpx/pydantic/sqlalchemy 与 Chromium 截图端口，不额外引入。

## 命令（宿主命令表，/help 可查；群聊需先 @机器人，私聊直接发）

| 命令 | 权限 | 说明 |
|---|---|---|
| /监听 <房间号|短号|链接> | 次级管理员 | 本群开始监听，自动开启开播+下播推送 |
| /取消监听 <目标> | 次级管理员 | 取消监听 |
| /监听列表 | 所有人 | 列出本群监听与推送开关 |
| /开播推送 <房间号> 开|关 | 次级管理员 | 单独开关开播推送 |
| /下播推送 <房间号> 开|关 | 次级管理员 | 单独开关下播推送 |
| /开播状态 | 所有人 | 实时查询并生成总览图 |
| /卡片风格 [风格名] | 次级管理员 | 查看/设置本群卡片风格 |
| /config | 次级管理员 | 查看/修改本群设置（含开播/下播 AI 回复开关） |

## 与直播间交互/定时任务的关系

本插件只做开播/下播监听与通知。直播弹幕交互、发弹幕、读历史、定时弹幕由 B站模块的 /直播互动 命令与 bilibili_live 技能提供，与监听分开、不绑定；交互只在该房间开播时进行，下播不发送。

## 配置

插件配置在面板「插件」页维护（plugin.toml 的 [config] 为默认值）：轮询间隔、请求超时、B站 Cookie、UA、并发数、卡片风格、默认推送开关、AI 回复开关等。

## 边界

- 不做 B 站视频搜索/看视频接入（用户指示暂不接，后续再设计）。
- 真实开播/下播推送与 AI 回复仍需真实直播间验证；插件测试默认跳过网络用例。
